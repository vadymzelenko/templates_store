# Template Store — витрина готовых сайтов

Next.js 16 + Tailwind 4 + Framer Motion. Деплой — Vercel (ветка `main`).

## Что где
| Путь | Что это |
|---|---|
| `app/page.js` | Витрина: поиск по нише, фильтры по отраслям и возможностям, каталог, «Как работаем» |
| `app/templates/[slug]/page.js` | Страница шаблона: цена, что умеет, детали, похожие, кнопки «Обсудить в Telegram» и «Живое демо» |
| `lib/templates.js` | База шаблонов (лёгкая CMS) — **сюда добавлять новые карточки** |
| `lib/industries.js` | 22 отрасли и ~300 ниш, по ним работает поиск |
| `lib/search.js` | Логика поиска и ссылка на Telegram |
| `public/projects/**` | HTML-лендинги |
| `sites/*` | Отдельные Next.js-лендинги со своими зависимостями (собираются в `public/projects/<slug>/`) |
| `scripts/build-sites.mjs` | Сборка `sites/*` в статику |
| `app/demo/*` | Демо на Next.js с рабочей онлайн-записью (демо-режим) |
| `public/previews/*.jpg` | Обложки карточек |

## Что умеет витрина
- **Умный поиск** (`lib/search.js`): синонимы и разговорные слова («зубы», «тачка», «потоп»), опечатки, украинский/польский/английский, подсказки под строкой.
- **Карточки** (`components/store/Card.js`): клик по картинке открывает живой сайт, при наведении сайт в карточке прокручивается.
- **«Как работаем»** (`components/store/HowWeWork.js`): на десктопе лента едет вбок при прокрутке, на телефоне листается пальцем.
- **Заказ** (`components/store/OrderWizard.js`): пять коротких шагов, в конце — готовое сообщение в Telegram.
- Мягкий скролл (Lenis) и появление блоков при прокрутке на всех страницах.

## Фото
Фото — с Unsplash, список в `lib/photos.js`. Если картинка не загрузилась, вместо битой иконки остаётся спокойный фон
(`components/ui/Photo.js`). Чтобы поставить свои фото, замените id в `lib/photos.js` или передайте `src` в `<Photo>`.

## Как добавить шаблон
1. Положите HTML в `public/projects/<папка>/<файл>.html` (или сделайте страницу в `app/demo/<slug>`).
2. Добавьте объект в `lib/templates.js`:
   - `industry` — ключ отрасли из `lib/industries.js` (`beauty`, `medicine`, `auto`, `food` …);
   - `category` — ниша, которая видна на карточке;
   - `badges` — короткие метки («Онлайн-запись», «Калькулятор», «Портфолио» — по ним работают фильтры);
   - `fits` — ниши, под которые шаблон легко переделать (поиск покажет его и по ним);
   - `liveDemoUrl` — относительный путь (`/projects/...html` или `/demo/...`);
   - `coverImage` — `/previews/<slug>.jpg` или любая ссылка на картинку.
3. Обложки снимает GitHub Actions (workflow **Previews**): он запускается сам после изменения `lib/templates.js`, снимает недостающие обложки и коммитит их в ветку. Вручную: Actions → Previews → Run workflow (можно указать slug'и и пересъёмку). Локально: `npm run dev`, затем `npm run previews -- http://localhost:3000` (`--missing` — только недостающие, можно перечислить slug'и) — снимет первый экран (`public/previews/`) и длинный скриншот для прокрутки в карточке (`public/previews/tall/`). Запускайте там, где грузятся фото Unsplash, чтобы они попали в обложки.

`telegramUrl` можно оставить пустым — кнопка сама откроет чат @vzbbme с готовым текстом.

| `/demo/fitness` | расписание недели на первом экране, бронь мест |
| `/demo/cleaning` | слайдер до/после, калькулятор уборки |

Логика слотов для записи — `components/demo/useSlots.js`, данные каждого демо — `app/demo/<slug>/data.js`.
Демо-запись ничего не отправляет; в рабочей версии подключается booking engine.
Рабочий booking engine (Supabase, magic link, кабинет, CRM) лежит в ветке `supabase-crm-landings` и подключается к проекту клиента при заказе.

## Лендинги на Next.js (`sites/`)

Крупные лендинги живут в `sites/<slug>` как самостоятельные Next.js-проекты: свои зависимости, свой `next.config.mjs`, их можно запускать и развивать отдельно (`cd sites/<slug> && npm install && npm run dev`).

| Папка | Проект | Адрес в витрине |
|---|---|---|
| `sites/enigma-photo` | Enigma Studio — сайт фотографа (GSAP, Lenis) | `/projects/enigma-photo/` |
| `sites/language-school` | «Вылет» — языковая школа с админкой (GSAP) | `/projects/language-school/` |
| `sites/vibe-bistro` | VIBE*BISTRO — лендинг бистро (Tailwind) | `/projects/vibe-bistro/` |
| `sites/stille` | Stille — лендинг цифрового продукта (Tailwind) | `/projects/stille/` |

`npm run build` сначала выполняет `npm run sites:build`: каждый сайт собирается статическим экспортом (`output: 'export'`, `basePath: /projects/<slug>`) во временной копии и кладётся в `public/projects/<slug>/`. Эти папки не хранятся в git, их создаёт сборка. Собрать один сайт: `npm run sites:build -- stille`.

В статической версии нет серверной части: у языковой школы из копии убираются админка и API, а форма заявки работает в демо-режиме (`NEXT_PUBLIC_DEMO=1`) и ничего не отправляет. Полная версия с админкой запускается из `sites/language-school` через `npm run build && npm start`.

`next.config.mjs` витрины переписывает адреса `/projects/<slug>/...` на соответствующий `index.html`, поэтому ссылки вида `/projects/stille/` работают.

Чтобы добавить новый сайт: положить проект в `sites/<slug>`, добавить в его `next.config.mjs` блок со `STATIC_EXPORT` и `BASE_PATH` (как в соседних сайтах), вписать `<slug>` в `SITES` в `scripts/build-sites.mjs` и в `.gitignore`, добавить карточку в `lib/templates.js`.
